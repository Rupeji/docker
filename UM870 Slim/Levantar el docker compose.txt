⚠️ El último "toque" friki de seguridad antes de arrancar:
Si te fijas en la documentación del repositorio que acabas de rescatar, 
el contenedor corre internamente bajo un identificador de usuario específico (UID 1001). 
Para evitar que Docker se quede colgado por un problema tonto de permisos de escritura en tu carpeta de metadatos, 
el día del despliegue en Arch Linux, justo antes de lanzar el docker compose, 
ejecuta este comando en tu terminal SSH:

mkdir -p /opt/docker/lancache-dashboard/data && sudo chown -R 1001:1001 /opt/docker/lancache-dashboard/data


docker compose up -d --build
